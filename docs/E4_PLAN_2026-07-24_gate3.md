## 4. NEW EvaluateTier1() (touch point D - the one new function)
Guard: return unless InpEnableTier1 && levelCount>0 && direction!=0 &&
       !trailingActive.
GATE A (depth, O2): openCount = live tracked positions; if openCount <
       InpTier1MinTrades -> return (dormant; D-1/D-2, O-3).
GROUP FORMATION (A-1, G-1): anchor = lowest surviving LEVEL NUMBER (== oldest,
       C1); profitables = every live tracked position with positive P/L at this
       tick (direction-derived: SELL profits below entry, BUY above). Group =
       anchor + profitables (anchor may itself be profitable; C2 - threshold
       alone governs).
GATE B (profit, O2): far price DIRECTION-DERIVED - SELL->Ask, BUY->Bid (O4).
       groupVWAP = ComputeWeightedVWAP(group). margin (pts) = dir<0 ?
       (groupVWAP - far)/_Point : (far - groupVWAP)/_Point. [sign confirmed at
       build against worked ref: SELL VWAP 1.910008 - Ask 1.90848 = 152 pts.]
       If margin < InpTier1MinProfitPts -> return (T-4/T-6). HARD INVARIANT:
       margin>= threshold>0 => combined P/L strictly > 0 (G-3).
FIRE (O5, X-1..X-3): close PROFITABLES FIRST (descending ticket), ANCHOR LAST,
       each via CloseLegAtMarket. If ANY profitable leg fails after the sealed
       retry -> ABORT: do NOT touch the anchor; return (X-2). Anchor-close fail
       after all profitables closed -> anchor stays open, realized = pure
       profit subset >= 0 (X-3). Then RETURN FROM THE TICK (see section 5).
  -> T-1..T-6, A-1..A-4, G-1..G-3, X-1..X-5, O-1..O-3, D-1..D-2.
